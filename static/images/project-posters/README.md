# Project poster images

Add optional 16:9 JPG posters here. The portfolio automatically uses a poster when its filename matches one of these names:

- `credit-card-fraud-detection.jpg`
- `customer-segmentation.jpg`
- `sentiment-analysis.jpg`
- `titanic-survival-prediction.jpg`
- `on-demand.jpg`
- `deepfake-video-generation.jpg`

Until then, a built-in demo placeholder is shown.
